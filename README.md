# macrociv-data

Public data for MacroCiv, an Android app that shows political leanings, economic freedom, and civil liberties by country.

The app downloads the files below from the `main` branch. It checks the small `version.json` manifest before downloading `macrociv_data.json`.

- https://raw.githubusercontent.com/fieldnoteappstudio-dotcom/macrociv-data/main/macrociv_data.json
- https://raw.githubusercontent.com/fieldnoteappstudio-dotcom/macrociv-data/main/version.json

The data is updated automatically each week as elections happen.
